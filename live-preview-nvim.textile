h2. Why live-preview.nvim

live-preview.nvim shortens the feedback loop for technical writing. Instead of switching constantly between editor and browser, you can keep writing in Neovim while the rendered result updates in real time.

The plugin is especially useful for authors who work with more than plain Markdown and need first-class support for Textile, SVG, and diagram-heavy documents.

h2. What it supports

* Markdown
* Textile
* SVG
* Mermaid
* Graphviz / dot
* PlantUML
* Chart.js
* D2
* TikZ
* KaTeX
* mhchem
* Inline SVG-based content

h2. Why it is useful

* Stay inside Neovim while reviewing rendered output
* Preview Textile as a first-class format
* Work with diagrams, math, and technical notation in one workflow
* Export rendered SVG-based diagrams directly from the browser
* Switch between light and dark appearance while reviewing content

h2. Quick start

If you use Lazy, add the plugin and install the node dependencies:

bc.. {"hostmyapps-git/live-preview.nvim",
    build = "npm install --prefix .",
    config = function()
        require("live-preview").setup()
    end,
},

p. Start preview with:

bc. :LivePreview

p. Stop preview with:

bc. :LivePreviewStop

h2. Typical workflows

* Technical documentation with diagrams
* Textile-based CMS or website authoring
* Markdown notes with math and code blocks
* SVG review and refinement
* Fast feedback while improving layout and formatting

h2. Supported filetypes
